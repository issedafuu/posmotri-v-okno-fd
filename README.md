# Посмотри в окно

Проектная работа для Яндекс Практикума.

---

## Описание проекта
"Посмотри в окно" — это сайт, который позволит вам насладиться видом из окна разных городов в разное время суток.
## Технологии
1. HTML
2. CSS
3. JS
